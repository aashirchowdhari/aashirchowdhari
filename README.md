## Production Systems I've Shipped

A few things I've built end-to-end and that are running for real users today — not just prototypes.

**Growmatic** — Field-survey intelligence platform for FMCG retail
Custom YOLOv8 models for shelf-audit tasks (planogram compliance, share-of-shelf, out-of-stock detection) running under 2 seconds per image across 40+ SKU types. Backed by a 62-endpoint FastAPI + PostGIS geospatial engine serving 450,000+ retailers and optimizing 25,000+ sales beats. Driving 95%+ shelf compliance for the client.

**Talkobotic** — AI outbound voice-dialer platform
Campaign engine over Vapi.ai, Ultravox, and Twilio with 8 selectable LLMs and 27 TTS voices, per-agent RAG knowledge bases built with LangChain, async call orchestration via Celery + Redis, and GPT-powered post-call lead scoring — multi-tenant with full workspace isolation.

**WiseWatch** — Edge-cloud CCTV analytics
YOLO detection + ByteTrack tracking running on local GPU agents at client premises, streaming live analytics to a cloud dashboard over outbound HTTPS only — zero inbound ports required on-site, built for security-conscious deployments.

**TalentLens** — AI-powered resume screening and candidate ranking against job descriptions using LLM-based evaluation.
